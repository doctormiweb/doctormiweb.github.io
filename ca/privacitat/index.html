Política de privacitat de DoctorMi

DoctorMi sí que recopila i tracta dades per prestar el servei. No ven dades personals, no les utilitza per a publicitat i no fa seguiment entre apps o webs.

1. Responsable del tractament

ArnoHealth SL, Gran Via de les Corts Catalanes, 699, 2n 2a, 08013 Barcelona, Espanya. Contacte: info@onmedic.com.

2. Dades que tractem

  • Compte i contacte: nom, correu electrònic, telèfon, rol i identificador d'usuari.
  • Dades clíniques i de salut: al·lèrgies, medicació, antecedents, data de naixement, símptomes i informació inclosa en les consultes.
  • Contingut: consultes, missatges, imatges, documents i informació administrativa aportada per l'usuari.
  • Compres: producte, estat de subscripció i identificadors necessaris per verificar compres amb Apple o Google.
  • Dispositiu i ús: identificador d'instal·lació, token de notificacions, plataforma, estat de lectura i interaccions necessàries per oferir el servei.
  • Diagnòstic: errors tècnics i dades de fallada desidentificades. DoctorMi configura Sentry perquè no enviï PII, captures de pantalla ni reproduccions de sessió.

3. Per què les utilitzem

Per crear i protegir el compte, vincular pacient i professional, gestionar consultes i missatges, permetre adjunts, enviar notificacions, verificar subscripcions, oferir l'historial funcional de l'app, prevenir abusos i corregir errors.

4. Base jurídica

Tractem les dades necessàries per prestar el servei contractat o sol·licitat, complir obligacions legals i protegir la seguretat del sistema. Les dades de salut es tracten amb consentiment explícit i/o dins de la prestació assistencial per professionals autoritzats, segons correspongui.

5. Proveïdors

Utilitzem Supabase per a autenticació, base de dades i emmagatzematge; Firebase Cloud Messaging per a notificacions; Sentry per a diagnòstic tècnic desidentificat; Apple o Google per a inici de sessió i compres; i Formspree amb Google Workspace per a la tramitació del formulari de contacte web. Aquests proveïdors processen dades sota les seves condicions i els acords aplicables.

6. Conservació i eliminació

Conservem les dades mentre el compte estigui actiu o siguin necessàries per prestar el servei i complir obligacions legals. L'usuari pot eliminar el compte des de l'app. També pot sol·licitar accés, rectificació, supressió, limitació, oposició o portabilitat escrivint a info@onmedic.com. Consulta els passos i terminis de supressió del compte.

7. Seguretat i transferències

Apliquem xifrat en trànsit, control d'accés, Row Level Security i registres sense PII. Quan un proveïdor tracta dades fora de l'Espai Econòmic Europeu, s'apliquen les garanties legals corresponents, com decisions d'adequació o clàusules contractuals tipus.

8. Reclamacions i canvis

Pots presentar una reclamació davant l'Agència Espanyola de Protecció de Dades. Publicarem en aquesta pàgina qualsevol canvi material d'aquesta política.
