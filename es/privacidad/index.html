Política de privacidad de DoctorMi

DoctorMi sí recopila y trata datos para prestar el servicio. No vende datos personales, no los utiliza para publicidad y no realiza seguimiento entre apps o sitios web.

1. Responsable del tratamiento

ArnoHealth SL, Gran Via de les Corts Catalanes, 699, 2.º 2.ª, 08013 Barcelona, España. Contacto: info@onmedic.com.

2. Datos que tratamos

  • Cuenta y contacto: nombre, correo electrónico, teléfono, rol e identificador de usuario.
  • Datos clínicos y de salud: alergias, medicación, antecedentes, fecha de nacimiento, síntomas e información incluida en las consultas.
  • Contenido: consultas, mensajes, imágenes, documentos e información administrativa aportada por el usuario.
  • Compras: producto, estado de suscripción e identificadores necesarios para verificar compras con Apple o Google.
  • Dispositivo y uso: identificador de instalación, token de notificaciones, plataforma, estado de lectura e interacciones necesarias para ofrecer el servicio.
  • Diagnóstico: errores técnicos y datos de fallo desidentificados. DoctorMi configura Sentry para no enviar PII, capturas de pantalla ni reproducciones de sesión.

3. Para qué los utilizamos

Para crear y proteger la cuenta, vincular paciente y profesional, gestionar consultas y mensajes, permitir adjuntos, enviar notificaciones, verificar suscripciones, ofrecer el historial funcional de la app, prevenir abusos y corregir errores.

4. Base jurídica

Tratamos los datos necesarios para prestar el servicio contratado o solicitado, cumplir obligaciones legales y proteger la seguridad del sistema. Los datos de salud se tratan con consentimiento explícito y/o dentro de la prestación asistencial por profesionales autorizados, según corresponda.

5. Proveedores

Utilizamos Supabase para autenticación, base de datos y almacenamiento; Firebase Cloud Messaging para notificaciones; Sentry para diagnóstico técnico desidentificado; y Apple o Google para inicio de sesión y compras. Estos proveedores procesan datos bajo sus condiciones y los acuerdos aplicables.

6. Conservación y eliminación

Conservamos los datos mientras la cuenta esté activa o sean necesarios para prestar el servicio y cumplir obligaciones legales. El usuario puede eliminar su cuenta desde la app. También puede solicitar acceso, rectificación, supresión, limitación, oposición o portabilidad escribiendo a info@onmedic.com. Consulta los pasos y plazos de eliminación de la cuenta.

7. Seguridad y transferencias

Aplicamos cifrado en tránsito, control de acceso, Row Level Security y registros sin PII. Cuando un proveedor trata datos fuera del Espacio Económico Europeo, se aplican las garantías legales correspondientes, como decisiones de adecuación o cláusulas contractuales tipo.

8. Reclamaciones y cambios

Puedes presentar una reclamación ante la Agencia Española de Protección de Datos. Publicaremos en esta página cualquier cambio material de esta política.
